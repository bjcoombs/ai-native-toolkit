# Changelog

One section per [GitHub release](https://github.com/bjcoombs/ai-native-toolkit/releases), newest first. The release notes on GitHub are the record of what changed: each is generated from the merged pull requests and grouped by label (`.github/release.yml`). This file is the index to them, so it links each release rather than copying its notes.

- A `v<version>` release is the plugin at that version; `/plugin update` installs it.
- A `standalone-skills-v<version>` release holds the standalone skill ZIPs built at that version.
- Changes to the `/assess` version counters (method, artifact schema, maturity model and the rest) are recorded per counter in [`skills/assess/changes/history/`](skills/assess/changes/history/).

The release pull request adds the new sections at the top ([Releasing](docs/contributing/release.md#changelog)).
