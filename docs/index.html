AI Native Toolkit · /assess

How much can an AI agent safely do in your repository?

/assess tells you how much an AI agent can safely do in your repository on its own, and the one change that would let it do more.

The ladder

Every repository sits on one of four Steps. Each Step is a level of trust you can give an agent. Between Steps is a gate: one concrete thing your repository must enforce before the next level of trust is safe.

Example position. Your report marks your own Step and your own next gate.

What the report says first

The report opens with three lines. Read those and you know where you are and what to do next.

Step 2 · Supervised agent PRs · contracts in place
Next: Step 3 · Unattended agent PRs unlocks when CI runs the tests
Practices in place: 4 of 9 measured, 2 verified

Example for a repository at Step 2. In plain words: an agent can open pull requests, a person reviews each one, and making CI run the tests is the next step up.

The one thing to do

Close the next gate. The report names exactly one change, with the evidence it found and why it matters. Everything else in the report is detail you can read later.

Why gates, not a score

A score rewards collecting practices, and more is not always safer. A Step needs its gates and enough practices in place, and the gates come first: collecting more practices never lets you skip one.

Behind the Step: the evidence

One square per condition, one row per practice, such as agent instructions, CI or code review. A practice has two levels, so its row has two squares: level 1 means it is in place, level 2 means it meets the stronger bar. Dark teal is met and verified by a run, mid teal met and measured from the code, pale teal met but only declared, grey not met yet, hatched not measured.

Four words

Step
How much you can trust an agent here, from 1 (it helps) to 4 (it runs loops on its own).
Gate
The one guarantee that must hold before the next Step is safe.
Practice
One thing a healthy repository does, such as committing agent instructions or reviewing every merge.
Level
How fully a practice is in place: level 1 in place, level 2 the stronger bar.

Try it

  1. Install the plugin in Claude Code: /plugin marketplace add https://github.com/bjcoombs/ai-native-toolkit, then /plugin install ai-native-toolkit@ai-native-toolkit.
  2. In your repository, run /assess.
  3. Read the first three lines, close the next gate, run it again and watch the Step move.
