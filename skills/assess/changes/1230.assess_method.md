- issues #1230 and #1233. The deterministic report is titled with the repository's name from
  its `origin` remote, the name only, and falls back to the checkout directory's name when
  there is no remote, so a `<repo>-main` or worktree checkout no longer titles the report after
  the directory. A skill's script that a test outside the skill folder names, by the
  skill-script-tests check's `tested_elsewhere` matcher, now has a test file in the sibling-test
  probe, so `test_focus` reads it as `sibling_test_only` (test file present, coverage
  unmeasured) instead of `unsupported`, and the hotspot page's "Has test file" row agrees. On
  this repository `skills/ghsync/scripts/ghsync.sh` and `skills/ghreport/scripts/ghreport.sh`
  move from `unsupported` to `sibling_test_only`.
