- three hollow cases now read unmet or unknown (issue #922):
  - Layer 0 level 1: an instruction file holding nothing beyond headings and blank lines
    is a stub and does not count; `layer_grades.instruction_presence` reads `stub` and
    `instruction_file_present` false. An alias inherits its target's stub flag, and a
    stub root file with a nested file beside it reads by the nested file.
  - Layer 1 rung 1: a telemetry dependency in a manifest alone is declared, not counted.
    Rung 1 needs a logger or telemetry library import in production source, a launch
    line (`opentelemetry-instrument`, `ddtrace-run`, `newrelic-admin run-program`, a
    `node --require` auto-instrumentation entry point, a telemetry `-javaagent:` jar) or a
    committed collector config. Telemetry library imports are read for Python,
    JavaScript and TypeScript, Go, the JVM, C#, Rust, PHP, Ruby, Swift and Dart.
  - Layer 7 level 1: a review app's config file with no CI review step reads not measured
    while `review_reality` is unread, with `review_reality`'s reason (the `fleet
    --platform` hint), since the app may not be installed.
