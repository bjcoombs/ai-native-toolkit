- run-context.json gains `pack` and `packs` with `--pack FILE` (issue #1273): `pack.<pack>.<check>`
  holds each practice-pack check's boolean or file count, or `{available: false, reason}` with
  `unreadable_file`, `unparsable_file` or `unsupported_yaml`; `packs` lists each pack's `name`,
  `version` and `sha256` in pass order. Without `--pack` neither key is written, so the file is
  unchanged. The fleet run stamp gains `packs` (written only with a pack; absent reads as no pack),
  and a packs difference refuses a comparison.
