- issue #1505, a bare pointer file is delegation. A root `AGENTS.md` whose only content is
  one line naming another root instruction file (`The instructions live in
  [CLAUDE.md](CLAUDE.md).`) makes that file canonical in `agent_consistency`, and links as
  `pointer`; a one-line `CLAUDE.md` naming `AGENTS.md` links as `pointer` for Claude Code too.
  Neither pair raises `claude_shadows_agents`. A pointer line with any other instruction (a
  second line, a second sentence, an HTML comment, inline code other than the file name)
  stays a separate file, as before. On a repository with that layout, `conflicts` and
  `unlinked` can fall and the `agent-consistency` row can rise.
