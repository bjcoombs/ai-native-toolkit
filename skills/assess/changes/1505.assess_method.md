- issue #1505, a bare pointer file is delegation. A root `AGENTS.md` whose only content is
  one short line naming another root instruction file at its own level (`The instructions
  live in [CLAUDE.md](CLAUDE.md).`) makes that file canonical in `agent_consistency`, and
  links as `pointer`; a one-line `CLAUDE.md` naming `AGENTS.md` links as `pointer` for Claude
  Code too. Neither pair raises `claude_shadows_agents`. A pointer with any other content (a
  second line, an HTML comment, a second sentence or clause, a joining word such as `and`,
  `then` or `never`, inline code other than the file name, more than 12 other words, or a
  path such as `docs/CLAUDE.md`) stays a separate file, as before. On a repository with that
  layout, `conflicts` and `unlinked` can fall and the `agent-consistency` row can rise.
