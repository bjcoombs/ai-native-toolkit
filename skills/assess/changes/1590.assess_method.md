- CI hazards (issue #1590): the Jenkins `junit` step is read in a Jenkinsfile only, so a GitHub
  step named "Upload junit (XML) reports" no longer clears `test_failures_ignored`. A Maven
  command inside a followed script or make recipe now adds the poms it reads; every CI step
  that runs the same file adds its commands, not only the first; and a setting inside a local
  composite action counts once, as the action, not also as the workflow that calls it.
