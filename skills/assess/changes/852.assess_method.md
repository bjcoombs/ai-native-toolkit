- docs kept true by CI (issue #852): `lib.ci.docs_kept_true` reads the GitHub Actions
  workflows and `.gitlab-ci.yml`, following steps through the shared CI-step follower (a
  committed script, a make recipe), for a regenerate-then-diff step, a verify and update
  script pair, or doc examples run as tests (`--doctest-modules`, `--doctest-glob`,
  `python -m doctest`, a Sphinx doctest builder, `cargo test --doc`, `--markdown-docs`,
  mdtest; or `pytest` with a doctest flag in the root pytest configuration). Masked lines
  (#775) never count.
- doc staleness: a doc in a subtree such a check names (the diff's or the doctest run's
  literal path arguments) carries `kept_true_by` and reads fresh, so `summary.stale_docs`
  and `stale_pct` can fall for repositories whose CI regenerates their docs.
