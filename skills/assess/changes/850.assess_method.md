- agent eval suites (issue #850): a folder named `evals`, `eval`, `evaluations`, `llm_evals`,
  `agent-evals` and the like, or a test tier `agent`, `agents` or `llm` under a test root, is
  a suite when a file in it names a model provider, client or harness, or it holds a
  recorded-response fixture; an `eval` folder holding an expression evaluator is set aside.
  CI runs it when a `run:` or `script:` command (read without quoted arguments, `echo` or
  comments) or a `working-directory:`, `with:` or `args:` value in a CI file or repo-local
  action names its path, its dotted module or its folder as a `pytest -m` marker, directly or
  through one root `Makefile`, `justfile` or `package.json` target. A job id, a step name, a
  `paths:` or `changes:` filter, a never-true `if:`, and an `--ignore` or `-k` path are not runs.
  Its baseline is a committed snapshot, cached responses, tool-budget, baseline or golden file
  inside the folder.
