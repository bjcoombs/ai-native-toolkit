- agent eval suites (issue #850): a folder named `evals`, `eval`, `evaluations`, `llm_evals`,
  `agent-evals` and the like, or a test tier `agent`, `agents` or `llm` under a test root, is
  a suite when a file in it names a model provider, client or harness, or it holds a
  recorded-response fixture; an `eval` folder holding an expression evaluator is set aside.
  CI runs it when a CI file or repo-local action names its path, its dotted module or its tier
  as a `pytest -m` marker, directly or through one root `Makefile`, `justfile` or
  `package.json` target; a `paths:` or `changes:` filter and an `--ignore` path are not runs.
  Its baseline is a committed snapshot, cached responses, tool-budget, baseline or golden file
  inside the folder.
