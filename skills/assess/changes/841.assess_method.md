- issue #841, the doc graph and doc freshness read AsciiDoc: `.adoc` and `.asciidoc` files.
  `xref:` and `<<page.adoc#,...>>` page references, `include::` and `link:` to a doc are
  link edges; inside an Antora component an `xref` is an Antora page ID resolved against the
  module's `pages/` directory. An Antora nav file and a root `README.adoc` are entry points.
  A `README.adoc` is a directory's base doc after `README.md` and `SKILL.md`, and
  `CONTRIBUTING.adoc` is boilerplate. A repository without AsciiDoc reads as before.
