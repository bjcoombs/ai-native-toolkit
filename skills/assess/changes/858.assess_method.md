- the agent instruction-rewrite reading (issue #858): an agent job can write files when its
  effective scope names `contents` or `write-all`, or a gh-aw source's `safe-outputs:` holds
  `create-pull-request` or `push-to-pull-request-branch`. Its paths at risk are the root
  `AGENTS.md` and `CLAUDE.md`, every committed instruction file at the known locations and the
  job's own workflow file (with a gh-aw source's committed `.lock.yml`) and the CODEOWNERS
  file in effect. It is guarded when that CODEOWNERS (`.github/`, then the root, then `docs/`)
  names an owner on the last line matching each path. That guard matches globs as GitHub
  does: a single `*` stays within one folder, so `/.github/*` does not own a workflow. An undeclared scope
  is not counted.
- CODEOWNERS globs (issue #858): a pattern that opens with `**/` also matches at the root, as
  GitHub reads it, so `**/AGENTS.md` owns the root `AGENTS.md`. This applies to the ownership
  map the structure-drift signals read as well.
