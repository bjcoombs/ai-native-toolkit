- agent eval suites read GitLab includes as GitLab merges them (issue #1573): a suite run only
  from a file the root `.gitlab-ci.yml` includes now reads as run by CI, where it read unmet
  before. A root `script:` that replaces the included one is not a run. A job the merge does
  not settle (a missing `extends:` parent, an include under `rules:`) is not a run and leaves a
  baselined suite not measured (`eval_ci_unread`), as an include that cannot be read does. A
  hidden job (`.evals:`) runs only as far as a job takes it: by an anchor an alias in the same
  file uses, or by the key a `!reference` names. A job whose own `when:` is `never` or
  `manual` is not a run.
