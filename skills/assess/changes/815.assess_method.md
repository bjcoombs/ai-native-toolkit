- `agent_ops` finds committed agent workflows (issues #815 and #847). A GitHub Actions
  workflow counts when its `on` names `schedule` or an issue, pull request, review or
  discussion event and it runs an agent: an agent action, a headless agent CLI (`claude -p`,
  `codex exec`, `gemini -p`, `copilot -p`, `opencode run`) or a named model, in its own
  lines, a repo-local action or a local reusable workflow it calls. A GitHub Agentic
  Workflows source (`.github/workflows/*.md` with an `on:` in its frontmatter) counts by
  construction, and its `.lock.yml` is not counted again. A provider secret alone is not a
  sign. `routines_present` is now also true on a scheduled agent workflow.
