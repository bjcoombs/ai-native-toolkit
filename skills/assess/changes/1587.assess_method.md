- `backlog_ready` reads four false unmets left by #1406 and #1323 (issue #1587). Level 1: a
  form-encoded `body=/label ~name` in a curl notes call adds the label; an unquoted label ends at
  the `]` of a flow list (`script: [glab issue update 1 -l needs-triage]`); a quoted one-word
  GitLab reference (`~"ready"`) names a ready label in documentation. Level 2: on GitLab, a close
  after the last note of a full notes page is no longer taken as the first response (an unread
  note on page 2 may come first), so the response reads unread; an unanswered issue closed by its
  own author is owed no response and no longer counts as overdue in `first_response_met`.
