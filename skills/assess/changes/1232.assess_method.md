- Side effects of adding scc to the treemap (issues #1232, #1234, #1235). `*.svg` is a
  default treemap exclude, as scc scores a committed SVG as XML and a large diagram took the
  biggest blocks; `--include-artifacts` keeps it, so hotspot rows and findings move on a
  repository that commits SVGs. `self_referential_tests` reads the new `code_band` (the three
  top lists ranked over the files a per-function backend scored) instead of the lists over
  every scored file, so a run with scc lists the same paths as a lizard-only run of the
  same commit.
