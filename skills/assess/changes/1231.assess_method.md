- issue #1231, structure drift resolves an architecture-doc `./` or `../` link from the doc
  that holds it, and a plain path falls back to the doc's directory when it names nothing
  from the repo root. A token opening with `-` (an option such as `--path-separator /`) is no
  longer read as a path. `empty_ownership_patterns` drops these false entries, and
  `matched_patterns`, `boundary_patterns`, `coverage_ratio` and `architecture_modules[].files`
  rise where a repo's docs use relative links. On this repository the Tier 0 list falls from
  730 to 549 entries.
