- prior-level.json: a record under `models` whose model holds practice-pack rows also stores
  `packs`, each pack's `{name, version, sha256}` as counted (issue #1316). A pack edited in
  place keeps its name and its record, so the next run reads the sha256: when it differs,
  `since_last_run` sets `gates_gained` and `gates_lost` to null and reads "Pack changed since
  last run (<pack>); gates not compared", the tag profile strip draws no earlier dots, and the
  CI gate reports the gates as not compared. A record written before this change holds no
  `packs`, so its packs read "Pack contents not recorded by last run (<pack>)" once, never as
  unchanged. The `since_last_run` collector reads the run context's `packs` block.
