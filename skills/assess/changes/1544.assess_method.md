- skill-library edge cases (issue #1544): the frontmatter parser reads a key's whole scalar
  (`FmEntry.text`), so a `SKILL.md` whose `description` sits on the indented lines below the
  key now counts, and one with an empty `>` / `|` block is invalid. A symlinked `SKILL.md`
  takes its target's location and is listed in `shared_by_symlink`. Under `--scope`,
  `lock_files` and `hashed_manifests` list only files under the scope (manifests at each scope
  folder). `skill_disclosure.description_chars` no longer drops the first character of a
  description written below an empty `description:`. Other parser callers
  (`claude_config`, `agent_harness`, `instruction_placement`) read the same as before.
