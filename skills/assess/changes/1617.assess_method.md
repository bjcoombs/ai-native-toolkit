- API compatibility, apidiff checks written in a workflow step (issue #1617): a step's own `run:`
  that pipes apidiff into a check (`apidiff a b | grep -q . && exit 1`) counts with pipefail off,
  as it does in a followed script. An inline `$(apidiff a b)` test whose `&&` chain or `||`
  fallback holds the re-raise (`[ -z "$(apidiff a b)" ] || { echo broke; exit 1; }`,
  `test -n "$(apidiff a b)" && echo broke && exit 1`) counts, and an `if` test of apidiff's
  output with `then` on the next line counts, in a script and in a CI step. A brace group
  rescued by a passing `||` (`{ echo broke; false; } || true`) and an `if` block closed by
  `fi || true` on a later line no longer count when the re-raise is `false`; an `exit N` still
  counts, since it ends the shell before the `|| true` runs.
