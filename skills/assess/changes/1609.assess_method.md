  read as they should: a `shell:` given as a path (`shell: /bin/bash -e {0}`) is matched to its
  program by basename, so the step is read as bash or Python; a Python label command written as
  an f-string (`os.system(f"gh pr edit {pr} --add-label x")`) is read by its literal parts, with
  each value standing for one word and never for the program or the flag; and a step that runs
  Ruby (a `ruby` script a `run:` line names, or `shell: ruby`) whose code names an AI marker,
  in a repository where no step enforces, reads not measured (`ruby_unread`) rather than unmet,
  as no reader reads Ruby. Ruby that names no marker changes nothing.
