- instruction files skipped by pull request checks (issue #857): `lib/ci/ci_path_filters.py`
  reads the `paths` and `paths-ignore` filters of each pull request event of every GitHub
  Actions workflow that runs a check on pull requests, as GitHub matches them (`*` within a
  segment, `**` across, `!` re-includes, last match wins). An instruction file every such
  workflow filters out raises the `ci-instructions-unchecked` hazard, which holds the
  `instructions` gate. A filter it cannot read lets every file through.
