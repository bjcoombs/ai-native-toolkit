- API compatibility gaps (issue #1612): a step that `uses: joelanford/go-apidiff` counts as an
  apidiff run; an inline `[ -n "$(apidiff a b)" ]` test that decides a re-raise, and a re-raise
  on apidiff's own line that reads its output, count; an output file another command on that line
  writes no longer counts as apidiff's, and a re-raise counts only when the command that reads
  apidiff's output decides it, with the right polarity (`cat out.txt; go build || exit 1` and
  `test -s out.txt || exit 1` no longer count). `npm test` / `t` / `tst` follow the `test` script, and
  `bun test` no longer does. griffe is declared only for `griffe check` or a `[tool.griffe]`
  table, and a shell glob no longer reads as a GitLab YAML alias.
