- docs kept true by CI (issue #1589): a wrapper's own options are skipped before the
  program it runs is read (`uv run --locked pytest`, `poetry -C . run pytest`,
  `npx --yes mdtest`), so a pytest step behind them with a doctest flag in the root pytest
  configuration now meets the condition, and an install behind them
  (`uv run --locked python -m pip install`, `uv --directory . sync`) is no longer read as a
  regeneration before a `git diff --exit-code`.
- check commands (issue #1589): the wrapper valued options are one set,
  `lib.ci.check_command.WRAPPER_FLAGS`, shared with docs kept true. It gains
  `--with-editable`, `--with-requirements`, `-P`, `--env-file`, `--index` and `--env`, so
  `uv run --env-file ci.env mypy` reads as a lint run and no test check, where it read as an
  unknown check before.
