  program it runs is read (`uv run --locked pytest`, `poetry -C . run pytest`,
  `npx --yes mdtest`), so a pytest step behind them with a doctest flag in the root pytest
  configuration now meets the condition, and an install behind them
  (`uv run --locked python -m pip install`, `uv --directory . sync`) is no longer read as a
  regeneration before a `git diff --exit-code`.
