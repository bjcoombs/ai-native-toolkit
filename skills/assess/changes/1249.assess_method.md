- issue #1249, model-ci-gated readings (`ci_model_jobs` revision 2). False credit: a job
  `if:` that negates an event test (`(github.event_name == 'push') == false`) no longer narrows
  the route to gated; a called workflow's job conditions apply to each caller route before the
  worst is taken; a `workflow_call` no local job calls reads unknown (`called_workflow`) even
  beside a `workflow_dispatch`; GitLab jobs read as GitLab merges them, so a root
  `- when: always` over an included schedule-only model job reads ungated, and a merge that is
  not settled reads unknown (`merge_unread`). False unmet: `paths: ['*']` and a `paths:` list
  ending in a `!` exclusion (`['**', '!docs/**']`) gate; sign steps under different recognised
  gates combine them; a caller job whose `if:` is never true registers no route. Recall: an
  install or add word counts only as a package manager's subcommand, so `claude -p 'add tests'` is an
  `agent_cli` sign; a GitLab job whose model `script:` comes from an `extends:` template is
  found; nested local reusable-workflow calls carry the outer route; a local reusable-workflow
  caller job is never a model job itself; `draft == false` beside a label test keeps the
  `label` gate; a step `name:` naming a provider key is not a sign; a quoted `"on":` reads its
  filters; a remote reusable workflow under a gated caller no longer counts in `unread`.
- issue #1249, model-ci-gated readings (`ci_model_jobs` revision 3). Recall: `claude plugin eval`
  is an `agent_cli` sign, with options before or after `plugin` and `eval`, as a quoted command and
  across the lines of a block `run:` or `script:`, and inside a `$(...)` or backtick span in
  double quotes (`OUT="$(claude plugin eval .)"`); an `echo`, a `#` comment or a quoted argument
  naming it is not. False unmet: an install line of a versioned pip (`pip3.11 install`), `pipenv`,
  `rye`, `pixi` or `hatch` is not a sign.
- issue #1249, model-ci-gated readings (`ci_model_jobs` revision 4). Recall: an apostrophe outside
  quotes (`don't` in a heredoc body) no longer opens a single-quoted span to the end of the text;
  an unclosed `'` ends at the end of its line, so a later `claude plugin eval` is an `agent_cli`
  sign. A closed single-quoted mention, on one line or over several, is still not read.
