- guardrails reads the run scope (issue #956): a scoped run counts the flake8
  and mypy configs inside the scope only, as coverage_gate does, and names the
  configs outside it in not_read. A scope root with no ruff config is gated by
  the nearest ruff config at or above it, as ruff resolves it. Ruff's C901
  selection resolves select and ignore by specificity (C9 ranks with C90, an
  ignore wins a tie), so `select = ["C901"]` beside `ignore = ["C"]` is a
  complexity gate. A coverage floor's ratio form needs a decimal point and a
  standalone number, so "step 1" and "v1.0" no longer state a floor of 100.
