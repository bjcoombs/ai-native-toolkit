- the agent instruction-rewrite reading (issue #1602): a gh-aw frontmatter's `imports:` is
  read as YAML structure instead of by line matching. A mapping item whose `path:` is not its
  first key, a flow list that opens on the line after `imports:` and a quoted path holding a
  comma now read as imports. A remote import is `owner/repo/path@ref` with three or more path
  parts, so a local file name holding `@` stays local. A frontmatter on the way that does not
  parse, or opens with `---` and never closes, raises the `agent-rewrites-instructions` hazard
  for that job instead of reading as clear.
